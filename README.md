================================================================================
PRACTICAL 10: Secure Login and Session Management
================================================================================

OVERVIEW:
This practical covers implementing user authentication and session security in PHP.
It ensures that users can securely log in, access authorized pages, and log out safely.

KEY FEATURES & OBJECTIVES:
1. Password verification using PHP's password_verify() function.
2. Regenerating session IDs on successful login to prevent session fixation attacks.
3. Role-Based Access Control (RBAC) to redirect Admins and Students to their respective dashboards.
4. Implementing automatic session timeout due to user inactivity.
5. Secure logout mechanism that clears and destroys all session data.

TECHNOLOGIES USED:
- PHP Sessions & Cookies
- MySQL Database
- HTML5 / CSS3
- XAMPP / Web Server
